# My Fitness Bot — обновление с дневником питания

## Безопасное обновление существующего Railway-бота

1. **Перед изменениями**: сохрани копию текущего кода; если для данных нужна гарантированная точка восстановления, создай резервную копию PostgreSQL (Railway Backups, если доступно по тарифу, либо pg_dump). Не удаляй PostgreSQL-сервис, проект Railway или тома.
2. В существующем репозитории GitHub замени содержимое **исполняемого** Python-файла кодом из `main.py`. Если твой основной файл уже называется `main.py`, просто замени его содержимое. Если Railway запускает `bot.py`, можешь сохранить имя `bot.py` и заменить его содержимое. Не создавай второй одновременно работающий бот с тем же BOT_TOKEN.
3. Обнови `requirements.txt` содержимым из набора. Старый набор зависимостей можно дополнить, но нужны `python-telegram-bot[job-queue]`, `psycopg[binary]`, `openai`, `tzdata`.
4. В Railway → сервис Telegram-бота → Variables сохрани текущие `BOT_TOKEN`, `DATABASE_URL`, `TEST_MODE`. Добавь **OPENAI_API_KEY** (ключ из https://platform.openai.com/api-keys, для API требуется отдельный биллинг), опционально `OPENAI_MODEL=gpt-4.1-mini`.
5. Убедись, что Start Command в Railway запускает реальное имя файла: `python main.py` (или прежнее имя, если оставляешь прежний путь). Если уже существует конфигурация startCommand, не добавляй конфликтующие Procfile / railway.json.
6. Сделай commit в GitHub и проверь Railway → Deployments → Logs: `Bot is running`. Существующие таблицы `participants` и `progress` **не удаляются и не изменяются**; новые таблицы создаются командой `CREATE TABLE IF NOT EXISTS`.

## Быстрый тест в Telegram

- `/today` — существующий экран тренировок и новые кнопки «Питание сегодня», «Шаблоны блюд».
- Отправь `2 яйца, тост, кофе с молоком`: ИИ предложит калории/БЖУ. Нажми **Записать**.
- `/nutrition` — итог дня и список записей.
- Отправь **фото еды** (можно добавить подпись про граммы или ингредиенты); подтверди оценку.
- После добавления еды нажми **Сохранить шаблон**, затем `/templates` и `➕` рядом с блюдом.
- `/manual Омлет | 350 | 22 | 25 | 8` — ручной ввод, работает **без API**.
- `/calgoal 2500` — дневной ориентир; 2500 — стартовое значение примера, подстрой по реальным данным.
- `/weight 88.5` — запись веса на текущий день; `/weight` — последние 7 измерений.
- `/undofood` — удаление последней еды, добавленной сегодня.
- `/testnotify` / `/testreset` — прежний тест тренировок (сброс только тренировки тестовой недели).

## Важно

- Оценка по фото неточна, особенно масло/соусы/скрытые ингредиенты. Для точного ввода используй ручную команду.
- Бот не хранит фото в PostgreSQL, но отправляет фото и описания блюд в OpenAI API для обработки. Не отправляй приватные изображения. Вызовы API платные и не входят в подписку ChatGPT.
- ИИ оценивает еду только если указан `OPENAI_API_KEY`; ручной ввод, тренировки, вес и шаблоны работают без него.
- Логика «/undofood» удаляет лишь последнюю запись **за сегодня**, а «Сохранить шаблон» сохраняет одну из уже добавленных записей.
- По умолчанию время и даты считаются в зоне `Asia/Dubai`. Записи питания начиная с сегодняшнего дня не связаны с тестовой неделей тренировок.
- В этом обновлении нет автоматического определения калорий, потраченных тренировкой, и нет гарантии точного баланса энергии. Остаток = цель по **питанию** минус оценённое съеденное.
- При изменении схемы важные данные следует регулярно резервировать средствами PostgreSQL.
